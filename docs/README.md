# docs

Planning and protocol, separate from the record.

| file | what it is |
|---|---|
| `GOAL.md` | the four claims the project exists to earn or kill, and what would kill them |
| `PLAN.md` | milestones M0-M6, each with a kill criterion |
| `EXPERIMENTS.md` | simulator protocol, task set, success criteria fixed before collection |
| `NEXT.md` | what is built, what is not, the one next step |
| `TODO.md` | outstanding work and what "done" means for each |

The measurement log is `../NOTES.md` and it is the only place numbers are
authoritative. Anything here that disagrees with NOTES is out of date.
